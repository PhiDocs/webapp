# **App Name**: Safety Docs AI

## Core Features:

- Document Type Selection: Users can choose between APR (Análise Preliminar de Risco) and APT (Análise Preliminar de Tarefa) documents.
- Form Input with Company Branding: Users can fill out a form with company-specific information, including name and logo.
- Activity Description Input: Users input a description of the work activity to be performed.
- AI-Powered Safety Analysis: Based on the activity description, the AI tool generates relevant information such as risks, potential hazards, and preventive measures based on Brazilian Normas Regulamentadoras (NRs).
- EPI Recommendation: Based on the activity description, the AI will provide which EPIs (Equipamento de Proteção Individual) will be needed for the described activity
- Formatted PDF Generation: Generates a well-formatted PDF document containing the company information, activity details, AI-generated safety analysis, EPI recommendations, risks, potential hazards, and preventive measures.
- PDF Download: Allows users to download the generated PDF document.

## Style Guidelines:

- Primary color: Deep blue (#1A237E), conveying trust, reliability, and professionalism, reflecting the serious nature of safety documentation.
- Background color: Very light blue (#E8EAF6), provides a clean, non-distracting backdrop to ensure readability.
- Accent color: Cyan (#00BCD4), highlighting important actions and information while remaining harmonious with the primary blue.
- Body and headline font: 'Inter', a sans-serif typeface known for its readability and modern appearance, making the documents easy to understand.
- Clean and structured layout with clear sections for company information, activity details, and AI-generated content. Margins will be carefully adjusted to avoid content breakage across pages.
- Use safety-related icons to visually represent different categories or sections within the documents.
- Subtle animations for user interface elements such as button hovers and loading states to enhance user experience.
